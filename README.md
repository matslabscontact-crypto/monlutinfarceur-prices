# Mon Lutin Farceur : test des prix publics

Test manuel depuis GitHub Actions, sans compte Amazon ni cookies. Quatre ASIN, offre principale uniquement, contrôle du prix affiché et de la disponibilité.

Ce dépôt ne contient aucun accès à WordPress. Un échec de collecte est signalé et aucun prix ne doit être inventé ou prolongé au-delà de 24 heures. Le test initial ne constitue pas encore une mise à jour programmée du site.
